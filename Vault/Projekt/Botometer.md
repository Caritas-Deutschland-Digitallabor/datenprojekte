# Botometer

## Kurzbeschreibung
Botometer sammelt zunächst Daten von der Social-Media-Website Twitter über deren öffentliche API. Anschließend extrahiert es über tausend Merkmale in Bezug auf das Konto, Freunde, Netzwerk, Inhalt und Stimmung des betreffenden Nutzers. Schließlich verwendet Botometer ein Random-Forest-Klassifikationsmodell, das auf einem öffentlichen Datensatz trainiert wurde (von dem ein Teil manuell als Mensch oder Bot gekennzeichnet ist) und Tausende von verifizierten Bot-Konten, deren Tweets sowie Tweets, in denen sie erwähnt werden, enthält. Der Klassifikator gibt einen Wahrscheinlichkeitswert aus, der angibt, wie wahrscheinlich es ist, dass es sich bei einem bestimmten Konto um einen Bot handelt.
