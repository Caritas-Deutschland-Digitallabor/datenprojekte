# defalsif-AI

## Kurzbeschreibung
Das Forschungsprojekt defalsif-AI entwickelt medienforensische Werkzeuge, die es Nutzern ermöglichen, eine erste Einschätzung der Glaubwürdigkeit von Text-, Bild-, Video- oder Audiomaterial im Internet vorzunehmen. Dabei wird künstliche Intelligenz eingesetzt. Das Projekt konzentriert sich insbesondere auf politisch motivierte Desinformation. Ziel ist es, ein valides Werkzeug zur Analyse digitaler Inhalte im Internet aufzuzeigen, das eine erste Bewertung der Glaubwürdigkeit und/oder Authentizität von Texten, Bildern, Videos oder Audio ermöglicht. Dies schafft die Grundlage für weitere Handlungsempfehlungen.
