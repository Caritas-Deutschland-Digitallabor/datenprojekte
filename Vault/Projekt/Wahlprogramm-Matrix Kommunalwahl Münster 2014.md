# Wahlprogramm-Matrix Kommunalwahl Münster 2014

## Kurzbeschreibung
Ein Tool zum Vergleich von Abschnitten in Wahlprogrammen. Per Klick werden ähnliche Abschnitte zum Ausgewählten farblich hervorgehoben. Die Auswertung geschieht automatisiert mit NLP.
