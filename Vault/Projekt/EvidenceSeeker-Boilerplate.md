# EvidenceSeeker-Boilerplate

## Kurzbeschreibung
EvidenceSeeker-Boilerplate ist ein Open Source Code Template mit dem Organisationen eigene KI basierte Political Tech Apps zum Fact-Checking unkompliziert auf Grundlage vorhandener Wissensdatenbanken aufzusetzen können.
