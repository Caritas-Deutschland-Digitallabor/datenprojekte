# Web Scraping zur Erfassung von DRK-Wohnungslosenhilfsangeboten

## Kurzbeschreibung
Das Deutsche Rote Kreuz bietet bundesweit zahlreiche Hilfsangebote für wohnungslose Menschen, hatte jedoch keinen vollständigen Überblick über alle Angebote seiner Gliederungen. DSSG Berlin entwickelte gemeinsam mit dem DRK eine automatisierte Web-Scraping-Pipeline, die 483 Websites von DRK-Kreis- und Landesverbänden nach Hilfsangeboten für Wohnungslose durchsucht und auswertet. Mithilfe von NLP-Methoden wurden relevante Informationen wie Kontaktdaten, Öffnungszeiten und Tätigkeitsbereiche strukturiert extrahiert. Die Ergebnisse liefern dem DRK eine vollständigere Datenbasis als bisherige manuelle Umfragen und bilden die Grundlage für Anwendungen wie Karten, Chatbots und Empfehlungssysteme.
