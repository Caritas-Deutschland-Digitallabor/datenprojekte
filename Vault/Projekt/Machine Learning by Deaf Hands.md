# Machine Learning by Deaf Hands

## Kurzbeschreibung
Als gehörlose Menschen wählen wir in der KI- und Avatar-Forschung einen anderen Weg zur Barrierefreiheit von gehörlosen Bürgern: Wir bringen der KI mittels einer Vielzahl an Videomaterial die Gebärdensprache bei, so wie Menschen die Gebärdensprache auch lernen.
