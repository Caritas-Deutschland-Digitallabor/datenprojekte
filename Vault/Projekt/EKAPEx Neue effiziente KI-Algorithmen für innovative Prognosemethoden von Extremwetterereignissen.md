# EKAPEx: Neue effiziente KI-Algorithmen für innovative Prognosemethoden von Extremwetterereignissen

## Kurzbeschreibung
Das Projekt EKAPEx entwickelt eine <abbr title="Künstliche Intelligenz">KI</abbr>-basierte Niederschlagsvorhersage für Deutschland. Ein besonderer Fokus liegt dabei auf Vorhersagen zu Extremwetterereignissen. Zu diesem Zweck sollen möglichst leistungsstarke, aber auch ressourceneffiziente KI-Algorithmen entwickelt werden. Um bessere Prognosen zur erzielen, werden im Projekt einzigartige Datensätze der letzten 20 Jahre aus dem Global Navigation System (GNSS) verwendet.
