# QTrees 

## Kurzbeschreibung
Das Konsortium „Quantified Trees“ (kurz QTrees) zielt darauf ab, dem Baumsterben langfristig entgegenzuwirken, indem ein durch künstliche Intelligenz (KI) unterstütztes Vorhersagesystem entwickelt wird, das anhand einer Vielzahl von Daten akut trockenheitsgefährdete Stadtbäume frühzeitig identifiziert.
