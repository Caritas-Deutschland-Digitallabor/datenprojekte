# Circularity Tool Add-on: Smarter UX & AI for Decision-Making

## Kurzbeschreibung
Our project enhances the Circularity Tool add-on, developed in collaboration with BBSR and IBO. We improved the existing user flow of with AI-powered guidance and UX/UI enhancements, making circularity metrics more accessible and actionable for both experts and non-experts.
