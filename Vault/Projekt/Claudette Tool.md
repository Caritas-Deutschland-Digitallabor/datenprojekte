# Claudette Tool 

## Kurzbeschreibung
CLAUDETTE ist ein Tool, das KI nutzt, um potenziell unfaire Vertragsklauseln in Verbraucherverträgen und Datenschutzerklärungen zu identifizieren. Dabei kommen grammatikbasierte Ansätze zum Einsatz. Nutzer können Verträge innerhalb weniger Minuten per Copy-Paste prüfen lassen.
