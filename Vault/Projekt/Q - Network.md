# Q - Network

## Kurzbeschreibung
Zwischen Forschungsteams und wirtschaftlichen Firmen ist eine große Kluft. Durch Menschliche, Infrastrukturelle, Rechtliche und Finanzielle Hürden können nur wenige Forschungsteams einen Nachweiß zur Wirtschaftlichkeit bekommen. Quality - Network will diese Hürden schmälern.
