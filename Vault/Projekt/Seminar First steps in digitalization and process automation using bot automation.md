# Seminar "First steps in digitalization and process automation using bot automation"

## Kurzbeschreibung
The gap between cutting-edge available AI algorithms and the current state of automation and digitalization in most organizations is huge. We plan to create a training curriculum to offer very practice-relevant basics of process digitalization and bot automation (also called RPA)
