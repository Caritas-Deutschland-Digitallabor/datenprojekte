# Preventing Poaching 

## Kurzbeschreibung
Das Projekt versucht mittels maschinellem Lernen das Verhalten von Wilderern vorherzusagen. Das Modell lernt die Verhaltensmodelle der Wilderer aus den gesammelten Kriminalitätsdaten. Auf dieser Grundlage berechnet PAWS Patrouillenrouten und die Wahrscheinlichkeit ihres Erfolgs.
