# Senf.app Köln

## Kurzbeschreibung
Senf ist eine digitale Beteiligungsplattform für Städteplanungsprojekte, um den Stadtraum aktiv mitzugestalten. Dort können Bürger*innen ihre Visionen für die Stadt auf einer interaktiven Karte teilen, liken und kommentieren. Die Auswertung erfolgt automatisiert mithilfe von KI.
