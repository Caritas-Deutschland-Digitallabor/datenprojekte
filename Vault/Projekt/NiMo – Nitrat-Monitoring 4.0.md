# NiMo – Nitrat-Monitoring 4.0

## Kurzbeschreibung
Das intelligente System zur nachhaltigen Reduzierung von Nitrat im Grundwasser soll mithilfe von KI den Anteil von Nitrat im Grundwasser vorhersagen und so eine angemessene Reaktion und Prävention ermöglichen.
