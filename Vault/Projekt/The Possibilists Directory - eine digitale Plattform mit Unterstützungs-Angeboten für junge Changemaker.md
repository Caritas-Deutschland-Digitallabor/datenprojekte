# The Possibilists Directory - eine digitale Plattform mit Unterstützungs-Angeboten für junge Changemaker

## Kurzbeschreibung
The Possibilists ist eine von ChangemakerXchange initiierte global Allianz der weltweit größten Netzwerke für soziale Innovation. Via The Possibilists Directory geben wir Millionen junger Changemaker, Aktivist:innen und Sozialunternehmer:innen Zugang zu passgenauer Unterstützung.
