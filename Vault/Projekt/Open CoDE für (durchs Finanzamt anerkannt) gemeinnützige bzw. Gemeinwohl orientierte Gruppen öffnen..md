# Open CoDE für (durchs Finanzamt anerkannt) "gemeinnützige" bzw. Gemeinwohl orientierte Gruppen öffnen.

## Kurzbeschreibung
Open CoDE (https://opencode.de) für (durchs Finanzamt anerkannt) "gemeinnützige" bzw. "Gemeinwohl orientierte" Gruppen aus der Zivilgesellschaft (z.B. Vereine, Stiftungen, etc.) öffnen. Das unterstützt die Ehrenamtsbranche und wirkt umgekehrt positiv auf die Öffentliche Hand.
