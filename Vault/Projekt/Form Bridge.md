# Form Bridge

## Kurzbeschreibung
Deutsche Behördenformulare sind für Nicht-Muttersprachler unverständlich. Das Projekt wandelt sie in mehrsprachige, webbasierte Fragebögen um, die automatisch das korrekte deutsche Original-Formular generieren. So wird Bürokratie für alle zugänglich.
