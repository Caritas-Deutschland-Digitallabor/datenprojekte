# Mithilfe von Machine Learning Anomalien in Bienenstöcken erkennen

## Kurzbeschreibung
Maschinelles Lernen auf Sensordaten aus Bienenstöcken erkennt Anomalien und alarmiert Imker*innen rechtzeitig bei Notfällen.
