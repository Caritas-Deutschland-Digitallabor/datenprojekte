# IDETECT

## Kurzbeschreibung
Die Ergebnisse von IDETECT, unserem Tool für natürliche Sprachverarbeitung und überwachtes maschinelles Lernen, werden auf einer Plattform (IDMC-Monitore) visualisiert, die Informationen über gemeldete Konfliktvorfälle und das Auftreten von Naturgefahren anzeigt.
