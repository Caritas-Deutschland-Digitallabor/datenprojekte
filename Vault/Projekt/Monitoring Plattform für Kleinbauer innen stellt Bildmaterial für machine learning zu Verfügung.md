# Monitoring Plattform für Kleinbauer*innen stellt Bildmaterial für machine learning zu Verfügung

## Kurzbeschreibung
Mit den georeferenzierten Bildmaterialen unserer SaaS Plattform, die Informationen von Kleinbauer*innen und deren Felder und Kulturen enthält, kann maschinelles Lernen angewendet werden, um satellitengestützte Analysetools zu verbessern.
