# KI-basierte Prognose für freie Parkplätze / Parkräume im urbanen Raum

## Kurzbeschreibung
Eine Prognose zur Belegung von öffentlichen Parkplätzen / Parkräumen. Durch eine genaue Vorhersage können die knappen Ressourcen optimal genutzt werden. Der Zeitaufwand zur Parkplatzsuche wird stark reduziert. Ein gewichtiger Beitrag zum Klimaschutz wird praktisch möglich.
