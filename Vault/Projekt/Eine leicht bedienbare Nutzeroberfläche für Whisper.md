# Eine leicht bedienbare Nutzeroberfläche für Whisper

## Kurzbeschreibung
Whisper ist eine KI, die aus gesprochener Sprache Texte erstellt. Eine leicht bedienbare Benutzeroberfläche macht diese Sprache-zu-Text-Funktion für Menschen ohne Programmierkenntnisse zugänglicher. Weitere Funktionen wie die Erkennung von Sprecher*innen ergänzen das Projekt.
