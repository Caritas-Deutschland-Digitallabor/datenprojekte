# Monitoring von Hass im Netz mit einem simplen Tool - von AI4Democracy

## Kurzbeschreibung
Das Ziel ist die Entwicklung eines Tools, das es ermöglicht, gegen Hassrede und Fake News in sozialen Medien vorzugehen, insbesondere im Kontext von Wahlen.
