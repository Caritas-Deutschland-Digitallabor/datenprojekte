# Path protector

## Kurzbeschreibung
Kamera + KI = Erkennung von Falschparkern auf dem Radweg. Speichert Standzeit, Fotos, Nummernschild, Datum Uhrzeit und übermittelt an Parkraumüberwachung. Läuft autonom über Solar und Mobilfunknetz. Mobil oder fest aufstellbar.
