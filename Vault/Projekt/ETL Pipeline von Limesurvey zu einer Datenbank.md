# ETL Pipeline von Limesurvey zu einer Datenbank

## Kurzbeschreibung
Umfragedaten aus Limesurvey landen oft in unübersichtlichen Exporten. Wir bauen eine automatisierte Pipeline, die sie direkt in eine Datenbank überführt.
