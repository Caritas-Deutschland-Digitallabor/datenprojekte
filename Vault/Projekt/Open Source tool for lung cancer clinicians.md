# Open Source tool for lung cancer clinicians

## Kurzbeschreibung
Unterstützung von Bemühungen gegen Menschenhandel an Grenzübergängen und Flughäfen durch die Zusammenführung von Daten verschiedener Standorte und das Aufzeigen von Erkenntnissen, die den Befragern bessere Informationen darüber geben, welche Fragen gestellt werden sollten und wie diese zu richten sind.
