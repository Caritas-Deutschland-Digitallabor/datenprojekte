# Kidney Donation Algorithm

## Kurzbeschreibung
Ein an der Carnegie Mellon University entwickelter Computeralgorithmus vermittelte Ende letzten Monats lebende Nierenspender an medizinisch kompatible Transplantationskandidaten, als das nationale Organbeschaffungs- und Transplantationsnetzwerk (OPTN), betrieben vom United Network for Organ Sharing (UNOS), ein nationales Pilotprogramm startete, um die Anzahl der Nieren-Paarspende-Transplantationen (KPD) zu erhöhen.
