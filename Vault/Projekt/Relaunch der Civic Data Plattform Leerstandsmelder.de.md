# Relaunch der Civic Data Plattform Leerstandsmelder.de

## Kurzbeschreibung
Auf Leerstandsmelder.de können Bürgerinnen und Bürger leerstehenden Wohnraum eintragen, um Daten über teilweise illegalerweise nicht zur Nutzung freigegebenen Wohnraum zu sammeln – eine wichtige Grundlage für zivilgesellschaftliches Engagement im Bereich Wohnen. Das Civic Data Lab (CDL) unterstützte die letzten Schritte des Relaunches, mit dem das ehrenamtliche Team die Plattform auf neusten Stand brachte und die Bereitstellung von Daten für weitere Anwendungen ermöglichte.
